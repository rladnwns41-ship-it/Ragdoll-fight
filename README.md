# RAGDOLL FIGHT — 배포판

`RAGDOLL-FIGHT.html` 파일 하나가 전부입니다. 더블클릭하면 브라우저에서 바로 실행됩니다.
서버도, 설치도, 별도 파일도 필요 없습니다. (14MB — 3D 모델이 안에 들어 있습니다)

## 들어 있는 것

- three.js / cannon-es 물리 엔진
- 파이터·옥타곤·상자 3D 모델 (전부 내장)
- 27개 기술 + 8개 궁극기
- 4가지 규칙 모드 (기본 / 무중력 / 상자 폭풍 / 무한 스킬전)

## 조작

| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| Space | 점프 |
| F | 가드 |
| G | 잡기 (다시 누르면 놓기) |
| N / M | 잡은 뒤 내리꽂기 / 자이언트 스윙 |
| 1~0 | 기본기 |
| E I O P Q T U X Y Z | 특수기 |
| K L R ; , . V / | 궁극기 |
| 마우스 | 1인칭 시선 (상하좌우) |
| Tab | 액션바 접기 |
| Esc | 기권 / 로비로 |

## 온라인 대전

Firebase Realtime Database 를 씁니다. 첫 대전 찾기에서 주소를 물어보면
콘솔 상단의 `https://...firebasedatabase.app` 주소를 넣어주세요. 한 번 넣으면 저장됩니다.

방을 만들면 4자리 코드가 나옵니다. 친구가 그 코드로 들어오면 바로 5판 3선승이 시작됩니다.

**오프라인으로도 전부 놀 수 있습니다** — 혼자 연습 모드는 서버 없이 동작하고,
쿨타임·해금·궁극기 게이지가 전부 풀려 있습니다.
